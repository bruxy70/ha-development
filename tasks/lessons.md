# Lessons

- Marketplace skills must work in both Claude Code and Codex consumer workspaces. Resolve bundled resources from the skill/plugin location, not the current repository directory. Never assume repository-local Claude hooks or fixed MCP names are active for consumers.
- Preserve both client manifests and keep role source, reference and native Codex copies aligned.
- A missing/skipped hook or unavailable model/device test is not successful validation. Conditional scaffolding cuts need paired evidence before deletion.
